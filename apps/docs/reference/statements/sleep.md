# `sleep`

> **层**：L5 · **组**：Utility · **对应 JS**：延迟 / setTimeout 感

## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `ms` | number | 必填 | ≥ 0 |


## 示例

```json
{
  "type": "sleep",
  "params": { "ms": 100 }
}
```
